# Ehyoo Profile Page

solo.to 형태를 참고해 만든 모바일 중심의 개인 프로필·링크 페이지입니다.

## 파일 구성

- `index.html`: 페이지 전체 코드
- `avatar.svg`: 올블랙 프로필 이미지
- `favicon.svg`: 브라우저 탭 아이콘

## 로컬에서 열기

`index.html`을 브라우저로 직접 열어도 됩니다.

로컬 서버를 사용하려면 다음 명령을 실행하세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`으로 접속합니다.

## GitHub Pages 배포

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 최상위에 업로드합니다.
3. 저장소의 `Settings → Pages`로 이동합니다.
4. `Deploy from a branch`를 선택합니다.
5. `main` 브랜치와 `/root`를 선택한 뒤 저장합니다.
